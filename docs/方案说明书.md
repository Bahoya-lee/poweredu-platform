```
   └──────────────────────────────────────────────────────┘
```

设计要点：

1. **内核与 Web 解耦**：`server/engine` 不依赖任何 Web 代码，可作为 Python 库被脚本、Notebook、
   MATLAB 替代实验单独调用，便于后续做科研扩展。
2. **零第三方依赖**：不使用 numpy/Flask/Django，只用标准库 `http.server`、`sqlite3`、`complex`、
   `hashlib`。这既是"免安装、免授权"的技术基础，也让平台能在任何装有 Python 的机器上 5 分钟部署。
3. **前端无 CDN**：单线图与曲线用原生 SVG 绘制，断网机房同样可用（很多教学网站死在 CDN 上）。

## 3. 核心算法与实现

### 3.1 潮流计算（牛顿-拉夫逊法）

节点导纳矩阵按 π 型等效装配，变压器非标准变比 `t = a·e^{jθ}` 采用标准处理：

```
Y_ff = (y + jb/2)/a²      Y_ft = -y/conj(t)
Y_tf = -y/t                Y_tt = y + jb/2      （y = 1/(r+jx)）
```

节点功率方程 `S_i = V_i·conj(Σ_j Y_ij V_j)`，极坐标下功率不平衡量：

```
ΔP_i = P_i^spec - V_i Σ_j V_j (G_ij cosθ_ij + B_ij sinθ_ij)
ΔQ_i = Q_i^spec - V_i Σ_j V_j (G_ij sinθ_ij - B_ij cosθ_ij)
```

雅可比矩阵按解析偏导装配（`∂P/∂θ`、`∂P/∂V`、`∂Q/∂θ`、`∂Q/∂V` 四个分块），
每轮用列主元高斯消元求解修正量，直到最大不平衡量小于 `1e-8` p.u.。
收敛后回代发电机无功、支路两端功率、损耗与负载率；可选开启 PV 母线无功越限转 PQ 的重复求解。

### 3.2 三相短路（节点阻抗矩阵法）

```
Z_bus = [Y_bus + Y_gen'']⁻¹                       （Y_gen'': 发电机次暂态电抗并联支路）
I_f   = V_pre(k) / (Z_kk + Z_f)                   （金属性短路时 Z_f = 0）
ΔV    = -Z_bus[:, k] · I_f
I_f(kA) = I_f(p.u.) · S_base/(√3·V_base)
```

把潮流结果作为故障前运行状态，因此短路电流随实际运行方式变化，而不是固定假设 `V=1.0`。

### 3.3 暂态稳定（经典二阶模型）

1. 由潮流结果求发电机内电势 `E_i = V_i + jX'_i·I_i`；
2. 负荷等值为恒定阻抗 `y_L = conj(S_L)/|V|²`，发电机经 `jX'_i` 接入后做 **Kron 降阶**，
   得到只含 m 台机内节点的降阶导纳矩阵；
3. 电磁功率 `P_ei = |E_i| Σ_j |E_j| (G_ij cosδ_ij + B_ij sinδ_ij)`；
4. 转子摇摆方程用四阶龙格-库塔积分（步长 0.01 s）：

```
dδ_i/dt = 2πf (ω_i - 1)
dω_i/dt = [P_mi - P_ei - D_i(ω_i - 1)] / (2H_i)
```

5. 故障期间在故障母线并联近似接地支路，切除时刻撤除故障并断开指定线路；
6. 判稳条件：任意两台机最大相对功角差小于 360°，且未出现"角差大于 180° 并持续发散"；
7. 极限切除时间用二分搜索求得（默认误差 0.005 s）。

### 3.4 AI 助教

| 能力 | 实现方式 |
| --- | --- |
| 自然语言改算例 | 中文正则抽取"母线号 / 发电机号 / 数值+单位 / 母线对 / 百分比"，映射为 6 类操作：改负荷、改出力、改电压设定值、线路投切、变压器变比、全网负荷缩放 |
| 可解释性 | 每次修改都返回**操作清单**（对象、字段、修改前后数值），前端逐条展示，便于教学讲解 |
| 结果诊断 | 规则库：电压越限、线路过载、相角差过大、无功越限、网损与平衡机出力；输出等级 ok/warn/risk 与中文结论 |
| 报告生成 | 按实验报告规范填充：实验目的、系统模型表、潮流结果表、支路潮流表、结果分析、短路与稳定结论 |
| 大模型接入 | 兼容 OpenAI Chat Completions 协议；未配置 Key 或网络异常时自动降级到本地规则引擎，保证课堂不中断 |

## 4. 功能清单（可演示）

**工作台**

- 算例库切换（三机九节点、IEEE 14、单机-无穷大、10 kV 辐射馈线），支持"另存为自定义算例"。
- 母线/支路参数在线编辑，改完即重算；支持恢复原始参数。
- 单线图：平衡/PV/PQ 三类节点符号区分、有功流向箭头、负载率标注、越限自动红色告警。
- 结果视图：迭代收敛曲线（对数轴）、支路负载率柱状图、母线电压/相角表、支路潮流与损耗表。
- 短路视图：各母线短路电流柱状图 + 短路电流对照表。
- 稳定视图：功角摇摆曲线、转速偏差曲线、稳定结论与 CCT。

**教学**

- 教师：建课、发布任务（算例 + 要求 + 评分标准 + 截止日期）、查看全班提交、导出成绩 CSV。
- 学生：按任务载入算例、在线实验、提交结果、自动评分与批语、查看历史提交。
- 平台：账号角色（学生/教师/管理员）、会话令牌、PBKDF2-SHA256 加盐口令、操作日志。

## 9. 已识别的边界与后续演进

- 短路计算按节点阻抗矩阵法给出**工频周期分量有效值**，不含直流分量衰减与继电保护动作时序。
- 暂态稳定采用经典二阶模型（`E'` 恒定、负荷恒定阻抗），不含励磁调压、调速器与详细机电暂态。

## 10. 答辩要点（三句话讲清楚）

1. **合规**：教学不能用盗版，国外软件装不上、买不起——我们把仿真内核做成浏览器服务，零安装、零授权、内网可用。
2. **自主**：潮流、短路、暂态稳定三个内核全部自研，且用 IEEE 14 标准解和解析解做了数值回归，误差量级在 10⁻³ 以内。
3. **AI 赋能**：AI 不只是聊天窗口——它把"改算例、看结果、写报告"三段教学动作串了起来，教师发任务、学生做实验、系统自动批改，
   直接对应榜题"省去授权费、提高教学效率"的价值目标。
