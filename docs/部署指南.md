# 后端部署指南

平台后端就是一段 Python 程序，**不需要编译、不需要 pip 安装任何依赖**。默认运行方式是**仅本机模式**：
只监听 `127.0.0.1`，不开放端口、不动防火墙、不依赖局域网。

## 0. 后端由什么组成

| 文件 | 职责 | 说明 |
| --- | --- | --- |
| `server/app.py` | HTTP 服务 + REST 接口 + 静态页面分发 | 标准库 `http.server`，多线程 |
| `server/ai_assistant.py` | AI 助教 | 意图解析、结果诊断、报告生成，可选大模型 |
| `server/store.py` | 数据层 | SQLite 建表、演示数据、账号/课程/任务/提交/日志 |
| `server/auth.py` | 口令与会话 | PBKDF2-SHA256 加盐存储、会话令牌 |
| `server/engine/` | 仿真内核 | 潮流、短路、暂态稳定、算例库（无 Web 依赖，可单独调用） |
| `server/static/` | 前端页面 | 由后端直接托管，不需要另外装 Web 服务器 |

**运行时依赖：0 个第三方包。** 只要机器上有 Python 3.11+ 就能跑。

## 1. 默认模式：仅本机运行

```powershell
cd C:\Users\Musta\Documents\Codex\2026-10-04\na\outputs\poweredu-platform
python -m server.app --port 8000 --open
```

Windows 也可以直接双击 `start.bat`；Linux/macOS 用 `./start.sh`。

启动后的特征：

- 终端打印 `运行模式：仅本机（不开放端口，不受防火墙影响）`；
- `netstat -ano | findstr :8000` 只会看到 `127.0.0.1:8000`，不会出现 `0.0.0.0:8000`；
- 其他电脑无法访问，也不需要放行防火墙；
- 数据写入当前目录的 `poweredu.db`；未配置大模型密钥时 AI 走本地规则引擎，全程不发外网请求。

适用场景：教师备课出题、批改、单人做实验、离线机房自测。

## 2. 需要多人同时使用时怎么办

如果目标是"服务全校师生"，正确做法是**把平台放到一台固定服务器上**（学院机房服务器、学校虚拟化平台或云主机），
同学访问那台服务器，而不是访问某台教师笔记本。原因是：

- 教师笔记本一旦合盖、断网、换教室，全班就断了；
- 让同学的机器连入个人电脑，必须在个人电脑上开放端口并修改防火墙，安全边界变大；
- 服务器可以配固定域名、HTTPS、每日备份和统一身份认证。

> 如果确实要在教师机或教室内临时共享，程序**默认会阻止**对网络开放；必须显式加 `--allow-network` 才会监听非本机地址（见第 4 节）。

## 3. 服务器部署步骤

### 3.1 放置代码并启动

把整个 `poweredu-platform` 目录拷到服务器，只监听本机端口，前面挂反向代理：

```bash
cd /opt/poweredu-platform
export PYTHONIOENCODING=utf-8
python3 -m server.app --host 127.0.0.1 --port 8000 --allow-network \
        --db /var/lib/poweredu/poweredu.db
```

> 服务器上把服务绑在 `127.0.0.1` 再由 Nginx/IIS 转发，比拼在 `0.0.0.0` 更安全。

### 3.2 反向代理与 HTTPS

```nginx
server {
    listen 443 ssl;
    server_name poweredu.example.edu.cn;
    ssl_certificate     /etc/ssl/poweredu.crt;
    ssl_certificate_key /etc/ssl/poweredu.key;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3.3 无人值守运行

**Linux（systemd）**

```ini
# /etc/systemd/system/poweredu.service
[Unit]
Description=PowerEdu 电力教学仿真平台
After=network.target

[Service]
WorkingDirectory=/opt/poweredu-platform
Environment=PYTHONIOENCODING=utf-8
Environment=POWEREDU_DB=/var/lib/poweredu/poweredu.db
ExecStart=/usr/bin/python3 -m server.app --host 127.0.0.1 --port 8000 --allow-network
Restart=always
User=poweredu

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now poweredu
```

**Windows（计划任务，开机自启）** —— 管理员 PowerShell 执行一次：

```powershell
$action  = New-ScheduledTaskAction -Execute "python.exe" `
           -Argument "-m server.app --host 127.0.0.1 --port 8000 --allow-network" `
           -WorkingDirectory "C:\poweredu-platform"
$trigger = New-ScheduledTaskTrigger -AtStartup
Register-ScheduledTask -TaskName "PowerEdu平台" -Action $action -Trigger $trigger -RunLevel Highest
```

**Windows（NSSM 注册为服务）**：`nssm install PowerEdu C:\Python314\python.exe "-m server.app --port 8000 --allow-network"`，
再把"启动目录"设为平台目录。

### 3.4 仅在服务器上放行端口

只有平台直接对外（不经反向代理）时才需要，且**只在服务器上执行**：

```powershell
New-NetFirewallRule -DisplayName "PowerEdu 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private,Domain
```

## 4. 可配置项一览

| 配置 | 方式 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 监听地址 | `--host` | `127.0.0.1` | 默认仅本机；填非本机地址会被安全护栏拦截 |
| 对网络开放 | `--allow-network` 或 `POWEREDU_ALLOW_NETWORK=1` | 关 | 显式确认后才允许他人访问 |
| 端口 | `--port` | `8000` | 被占用时自动换端口，终端会打印实际地址 |
| 数据库路径 | `--db` 或环境变量 `POWEREDU_DB` | 当前目录 `poweredu.db` | 正式部署建议指向有备份的目录 |
| 演示账号初始口令 | `POWEREDU_DEFAULT_PASSWORD` | `PowerEdu@2026` | **正式上线务必修改** |
| 自动打开浏览器 | `--open` | 关 | 本机演示方便 |
| 大模型 API（可选） | `DEEPSEEK_API_KEY` / `OPENAI_API_KEY` | 未配置 | 不配置则完全离线，使用本地规则引擎 |
| 大模型地址/模型名 | `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`OPENAI_BASE_URL`、`OPENAI_MODEL` | 官方默认 | 可指向校内自建模型服务 |
| 访问日志 | `POWEREDU_VERBOSE=1` | 关 | 排错时打开，打印每个请求 |

安全护栏的实际表现：

```powershell
python -m server.app --host 0.0.0.0 --port 8000
# 已阻止对网络开放：当前平台默认只允许本机访问。
#   你指定了 --host 0.0.0.0，这会让同一网络内的其他机器也能连入本机。
#   如果确实需要，请显式确认后重试：
#     python -m server.app --host 0.0.0.0 --port 8000 --allow-network
```

## 5. 数据与备份

- 所有业务数据都在一个 SQLite 文件里（默认 `poweredu.db`），**复制该文件即为完整备份**。
- 建议每天定时复制并保留 30 天：

```powershell
Copy-Item C:\poweredu-platform\poweredu.db "D:\backup\poweredu-$(Get-Date -Format yyyyMMdd).db"
```

- 备份或迁移前先停服务；服务退出时会自动关闭数据库连接，文件不会被占用。
- 恢复出厂演示数据：停服务 → 删除 `poweredu.db` → 重新启动。

## 7. 健康检查与排错

```powershell
curl.exe http://127.0.0.1:8000/api/health
# {"ok": true, "service": "电真万确 · AI 赋能电力教学仿真平台", "version": "1.0.0", "llm": false}
```

| 现象 | 原因与处理 |
| --- | --- |
| 提示"已阻止对网络开放" | 这是默认安全护栏；确认要共享时加 `--allow-network` |
| 端口被占用 | 程序会自动换端口，终端会打印实际地址；也可显式 `--port 8080` |
| 页面打开但数据为空 | 数据库目录不可写；用 `--db` 指向有写权限的路径 |
| 登录提示账号口令错误 | 数据库是旧版本或口令已被修改；删除 `poweredu.db` 可恢复演示数据 |
| 提示 `python` 不是命令 | 安装 Python 3.11+，安装时勾选 "Add python.exe to PATH" |
| 想验证部署是否正常 | `python -m unittest discover -s tests -t .`，79 项测试应全绿 |
