电真万确 · AI 赋能电力教学仿真平台

面向武汉大学电气与自动化学院以及全校师生开放的电力系统教学仿真平台，由国产自主仿真内核、AI 助教、教学工作台三部分组成。

一、自主仿真内核

  • 潮流计算：极坐标牛顿-拉夫逊法，支持 PV/PQ/平衡节点、变压器非标准变比、无功限值校验。
  • 短路计算：节点阻抗矩阵法三相短路，输出各母线短路电流与电压跌落分布。
  • 暂态稳定：经典二阶模型 + 四阶龙格-库塔时域仿真，Kron 降阶到发电机内节点，二分法求极限切除时间。

二、AI 助教

  • 自然语言修改算例：负荷、出力、电压设定值、线路投切、变压器变比。
  • 结果诊断：电压越限、线路过载、相角差过大、无功越限、网损分析。
  • 一键生成实验报告草稿；配置大模型密钥后可自由问答。

三、教学服务

  • 教师端：建课、发布实验任务、设定评分标准、查看成绩并导出。
  • 学生端：在线做实验、提交结果、自动评分与批语。

四、部署与合规

  • 纯 Python 标准库实现，零第三方依赖、零客户端安装、零商业授权。
  • 默认仅本机运行（只监听 127.0.0.1，不开放端口）；一条命令启动：python -m server.app --port 8000。
  • 要服务全班/全校时，把平台部署到一台固定服务器，再通过反向代理发布，不要依赖个人电脑共享。

版本 1.0.0 · 数据保存在本机 SQLite 数据库，不上传外网。
