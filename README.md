# 电真万确 · AI 赋能电力教学仿真平台

面向全校师生的浏览器端电力系统教学仿真平台：**国产自主仿真内核 + AI 助教 + 教学过程管理**，
零客户端安装、零第三方依赖、零商业授权，用于替代教学中大量使用的盗版/授权商业仿真软件。

> 对应榜题：《电真万确-AI赋能电力教学仿真软件平台》（AI+科研赛道，电气与自动化学院）。

## 一、五分钟上手

```powershell
cd outputs\poweredu-platform
python -m server.app --port 8000 --open
```

浏览器访问 <http://127.0.0.1:8000/>，用下列演示账号登录：

| 账号 | 角色 | 可以做什么 |
| --- | --- | --- |
| `student01` | 学生 | 做实验、AI 对话、提交结果、查看得分 |
| `teacher01` | 教师 | 建课、发布实验任务、查看成绩、导出 CSV |
| `admin` | 管理员 | 平台统计、日志查看 |

口令统一为 `PowerEdu@2026`（可用环境变量 `POWEREDU_DEFAULT_PASSWORD` 修改）。

**运行模式**：默认是**仅本机模式**——只监听 `127.0.0.1`，不开放端口、不需要改防火墙，其他电脑无法访问。
如果平台要服务全班/全校，请把它部署到一台固定服务器上（见 [部署指南](docs/部署指南.md)）。
程序对网络开放有安全护栏：只有显式加 `--allow-network` 才会监听非本机地址。

## 二、能做什么

**仿真工作台**

- 潮流计算：极坐标牛顿-拉夫逊法，支持 PV/PQ/平衡节点、变压器非标准变比、无功限值校验。
- 三相短路：节点阻抗矩阵法，输出各母线短路电流与故障后电压跌落。
- 暂态稳定：经典二阶模型 + RK4 时域仿真，绘制功角摇摆曲线与转速偏差曲线。
- 极限切除时间：二分搜索 CCT，用于讲解稳定裕度。
- 单线图可视化：潮流方向箭头、负载率标注、越限自动着色。

**AI 助教**

- 自然语言改算例：“把 5 号母线负荷增加到 120 兆瓦”“断开 6-7 线路”“全网负荷降低 10%”。
- 结果诊断：电压越限、线路过载、相角差过大、无功越限、网损统计，并给出调整建议。
- 一键生成实验报告草稿，可下载 Markdown。
- 可选接入大模型（`OPENAI_API_KEY` / `DEEPSEEK_API_KEY`），未配置时使用本地规则引擎，完全离线可用。

**教学服务**

- 教师端：建课 → 发布实验任务（含评分标准与截止日期）→ 查看班级提交 → 导出成绩 CSV。
- 学生端：载入指定算例 → 在线仿真 → 提交结果 → 自动评分与批语。

## 五、二次开发指引

- **新增算例**：在 `server/engine/cases.py` 中按 `_wscc9()` 的写法加入构造函数并注册到 `_BUILDERS`；
  母线需给出 `x`、`y`（0–100 画布坐标）以便单线图落点。
- **新增 AI 指令**：在 `server/ai_assistant.py` 的 `RULES` 中追加 `(名称, 正则, 处理函数, 选项)`，
  处理函数返回操作清单即可，前端会自动展示“操作清单”并重算。
- **更换大模型**：设置 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY`；接口地址与模型名可用
  `*_BASE_URL`、`*_MODEL` 覆盖（需兼容 OpenAI Chat Completions 协议）。
- **接入学校统一身份认证**：替换 `server/auth.py` 的校验逻辑，`Store.verify_user` 保持返回同样字段即可。

## 六、常见问题

**Q：需要联网吗？**
不需要。前端不引用任何 CDN，后端只用 Python 标准库，断网机房可正常上课。只有配置大模型 API Key 时才需要外网。

**Q：数据存在哪里？**
本机 `poweredu.db`（SQLite）。删除该文件即可恢复出厂演示数据。

**Q：能支持多少个学生同时使用？**
单机默认可支撑一个教学班（约 60 人）同时在线；如果面向全校，用 `--host 0.0.0.0` 发布到校内服务器，
并用反向代理（Nginx/IIS）转发到本服务即可。

**Q：为什么潮流不收敛？**
常见原因是网络被切成孤岛（线路被全部切除）、参数不合理（零阻抗）、或负荷远超可行域。
点击“潮流计算”后 AI 助教会给出具体诊断。
